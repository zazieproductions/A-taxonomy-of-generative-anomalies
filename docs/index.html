06 / PROVENANCEWHAT WE KNOW / WHAT WE DON’T

Keep the record honest.

The source files are preserved as supplied. Normalization creates a stable index; it does not turn missing values into defaults or cancelled runs into completed ones.

01

Stable ID, not text hash

Deduplication uses the original Workbench run ID. Duplicate appearances remain in provenance; conflicting versions would be reported rather than silently collapsed.

02

Export history is not a new run

Snapshot and compare-lane counts are recorded in the source manifest. Run arrays are authoritative for generation counts; a compare lane with a known run ID is not counted twice.

03

Recorded values stay recorded

Prompts, model identifiers, sampling settings, timestamps, status, reported token counts, finish reasons, and available logprobs are retained. Absent fields remain absent; administrative API key IDs are not copied into normalized records.

04

Masking is a view, not a rewrite

The canonical corpus is separate from this public projection. Common structured identifiers are masked in displayed text; the regex cannot guarantee privacy and the source data needs human review.
